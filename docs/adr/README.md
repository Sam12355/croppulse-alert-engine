# Architecture decision records

One file per decision that was expensive to make or would be expensive to reverse. The
format is context, decision, why, consequences. The consequences section is the point: a
record that only lists benefits is marketing, not a decision record.

- [ADR-0001: The decisions live here, the doing lives in the flagship](0001-decisions-not-doing.md)

Superseding is done by adding a new record that says what it replaces, not by editing the
old one. The history of a decision is part of the decision.
